Template Literals (Strings)

Created using backticks (`). They allow for embedded expressions and multi-line formatting without using the + operator.

1. String Interpolation

var user = "Alice";
var alerts = 4;

// The ${} injects variables directly
var msg = `Hello ${user}, you have ${alerts} alerts.`;

Template Literals (Advanced)

You can execute JavaScript expressions directly inside the placeholders or write multi-line HTML easily.

2. Executing Expressions

// Calling a function inside the string
var timestamp = `[${new Date().toLocaleTimeString()}]`;

3. Multi-Line Strings

// Press enter inside backticks to format
var htmlBlock = `
<div class='card'>
  <h2>Title</h2>
</div>
`;

Appending to an Element

When you need to keep previous data (like a log) and add new data to it, use the += operator on innerHTML.

function launchFunc(msg) {
    var msgdiv = document.getElementById("msg");
    var timestamp = `[${new Date().toLocaleTimeString()}]`;
   
    if (msg === 'Rocket1') {
        // The += operator prevents overwriting
        msgdiv.innerHTML += msg + " " + timestamp + "<br>";
    }
}
