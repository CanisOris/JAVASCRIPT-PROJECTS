JavaScript Depreciated

Modern Alternatives to document.write()

document.write() is deprecated because it blocks page parsing and can entirely overwrite the document if called after the page loads. Use these methods instead:

Method A: textContent (Safest)

Use for plain text. Highly secure against Cross-Site Scripting (XSS) because it refuses to parse HTML tags.

const container = document.getElementById('message-container');
container.textContent = "Hello, world!";

Method B: innerHTML

Use when you need to render actual HTML tags from a string. Warning: Do not use with untrusted user input.

const container = document.getElementById('message-container');
container.innerHTML = "<strong>Hello, world!</strong>";

Method C: createElement & appendChild

The standard programmatic way to build, configure, and insert new elements dynamically.

// Create a new paragraph element
const newPara = document.createElement('p');
newPara.textContent = "This is a new paragraph.";
newPara.style.color = "blue"; 

// Append it to the body
document.body.appendChild(newPara);

Method D: insertAdjacentHTML

Injects an HTML string precisely without overwriting existing child elements.

const list = document.getElementById('my-list');
// Inserts right inside the element, after its last child
list.insertAdjacentHTML('beforeend', '<li>New Item</li>');
